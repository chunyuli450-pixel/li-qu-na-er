# 李去哪儿

一个为自己和朋友设计的本地旅行路线规划网页。

## 直接使用

双击 `启动李去哪儿.cmd`，浏览器会自动打开网页。请保持弹出的运行窗口开启，关闭该窗口即可停止网页。

首次打开会显示一份杭州示例行程。点击右上角“地图设置”，填入高德开放平台的“Web端（JS API）Key”和对应的 `securityJsCode`，保存后即可搜索真实地点并显示路线。

## 已有功能

- 创建、切换和删除多个多日旅程
- 每天分别设置出发酒店与当晚酒店，支持换酒店当天从旧酒店出发、前往新酒店
- 高德地图地点搜索与路线展示
- 输入地点名称时自动显示地址联想，支持键盘选择和关闭结果
- 高铁站、火车站和机场可自动识别并直接加入路线，之后仍可编辑
- 先添加地址，再将地点完善为酒店、餐厅、景点或其他旅行卡片
- 酒店入住/退房、价格和房型；餐厅时间、人均与预约；景点门票等分类信息
- 每张地点卡片可编辑备注，并添加多个可自定义名称的网页链接；留空时默认打开高德地图
- 卡片提供美化后的删除、上移和下移按钮，电脑与手机均可操作
- 每段单独选择公共交通、自驾、打车、步行或骑行
- 时间优先或路程优先规划，可选择自动规划允许的交通方式
- 可选择是否计算当天最后前往当晚酒店的路段
- 公交蓝色实线、地铁按线路颜色、步行换乘绿色虚线，并标注换乘站
- 公共交通按行程预计出发时间逐段查询，显示乘坐时段、步行时间、总站数与预计票价
- 打车金额直接使用高德返回的估价；接口返回区间时保留区间，单值时显示为约价
- 地点停留时间、固定到达时间和迟到冲突提示
- 智能排序与拖动/按钮手动排序
- 浏览器本地保存
- 支持安装到桌面或主屏幕，并恢复上次使用的旅程和日期
- 首次联网打开后可离线启动、查看和编辑本地行程；地图、搜索和路线查询仍需联网
- 检测到新版本时提供“立即更新”和“稍后”选择，不会强制刷新正在编辑的页面
- 导入、导出包含高德密钥的行程文件
- 电脑与手机屏幕适配

## 安装与更新

使用支持可安装网页的浏览器打开后，页面会显示“安装到设备”按钮；也可以使用浏览器菜单中的“安装应用”或“添加到主屏幕”。安装后的名称为“李去哪儿”，以独立窗口启动。

可安装网页需要安全连接。电脑上的 `127.0.0.1` 本地地址可以直接使用；若要在手机上安装，需要通过 HTTPS 地址访问，普通局域网 HTTP 地址无法完整启用安装与离线功能。

发布新版本时需要同时更新 `public/sw.js` 中的 `CACHE_VERSION`。已安装的设备检测到新版后，会显示更新提示。

## 密钥提醒

导出的行程文件会按照产品设定包含明文高德 Key 和安全密钥。请只分享给可信的人，并在高德控制台设置合理的安全限制与调用额度。

## 开发说明

主要功能位于 `app/page.tsx`，界面样式位于 `app/globals.css`。本项目保留 React、Vite/vinext 与 Sites 项目结构；`dist-local` 是可直接本地运行的版本。
